# Караваника

Экономическая Telegram Mini App про производство ресурсов, рынок, караваны и гильдейские заказы.

## Запуск

Можно открыть `index.html` напрямую в браузере:

```bash
open /CodexGame/index.html
```

Или запустить локальный сервер:

```bash
cd /CodexGame
python3 -m http.server 8080
```

После этого игра будет доступна по адресу `http://localhost:8080`.

## Что внутри

- 21 ресурс в цепочках от сырья до ценных товаров;
- смены работников, склад и ежедневная аренда;
- пять городов с отдельными запасами, налогами, спросом и потреблением;
- региональные цены, которые растут от дефицита и падают от избытка;
- покупка и продажа товаров на выбранном городском рынке;
- караваны с временем доставки, пошлинами, охраной и риском потерь;
- городские контракты с премией к рынку;
- гильдейские проекты с крупными ресурсными целями и наградами;
- сохранение прогресса в `localStorage`;
- поддержка запуска внутри Telegram WebApp, если страница открыта как TMA.

При обновлении с ранней версии игры сохранение сбрасывается, потому что экономика и набор ресурсов изменены.
